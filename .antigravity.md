# Entorno de Ejecución
Este proyecto está estrictamente Dockerizado usando docker-compose. Tiene 3 servicios principales: `backend` (Java/JDBC), `ai-service` (Python/Node) y `postgres` (pgvector).

# Reglas Estrictas de Comandos para el Agente
1. **Prohibición del Host:** NO ejecutes comandos de instalación de paquetes (npm, pip, mvn, gradle), compilación, migraciones de base de datos o ejecución de tests directamente en mi máquina host.
2. **Uso de Docker Compose:** TODO comando que interactúe con el código o el entorno debe ser ruteado a través de Docker usando `docker compose exec`.
3. **Mapeo de Servicios (IMPORTANTE):**
    - Si el comando es para el backend principal, usa: `docker compose exec backend <comando>` (Ej: `docker compose exec backend ./mvnw clean install` o el gestor que use).
    - Si el comando es para el servicio de IA, usa: `docker compose exec ai-service <comando>` (Ej: `docker compose exec ai-service pip install -r requirements.txt`).
    - Si necesitas interactuar con la base de datos (psql), usa: `docker compose exec postgres <comando>`.
4. **Reinicio de servicios:** Si haces cambios en dependencias o variables, usa `docker compose restart <nombre_del_servicio>` o `docker compose up -d --build <nombre_del_servicio>`.
